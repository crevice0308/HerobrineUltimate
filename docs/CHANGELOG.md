# 0.1.0-alpha.2 — 2026-10-17

- **標準でチート OFF・OP 不要**に変更。所有者ではない一般プレイヤーも利用でき、OP を付与する必要はありません。従来の OP / 所有者 / UUID 制限は `require-permission=true` の任意設定にしました。
- 変身時の演出用落雷、パーティクル、短い画面フラッシュを実装・検証。パネル発光は G ボタンで独立切替し、端末設定へ自動保存します。
- K ボタンから標準のキー割り当て画面を開けるようにし、表示を実際のキーへ追従させました。キーボードとマウスの再割り当てに対応します。
- 小さい GUI のフォーカス移動、スクロール範囲のクリック判定、スライダーを画面外で離した場合の確定を修正しました。
- Mob の死亡・再読み込み・次元移動の登録追跡、既存の飛行 / 透明化と保存復元情報の扱いを補強しました。
- Fabric の実物の公式マッピング、Mixin AP、TinyRemapper を使う代替ビルドを追加。**Forge / Fabric 両方の通常 JAR**を作成し、2 回の再生成でそれぞれ同一 SHA-256 を確認しました。
- 実際の Minecraft で **両ローダー各 14 GameTest と各 85 クライアントステップが全成功**。全 12 カテゴリ、倍率、変身、キー設定、4 画面構成、死亡・復活、ネザー往復、ワールド保存・再開を検査しました。
- モデル 61、実 NBT 64、構成 33、Fabric 実 NBT / Netty パケット境界 89 の確認も成功。開発時に実画面 PNG、結果 JSON、ログと要求対応表を記録しました。公開ソースには個人向け素材と生ログを含めていません。

実行構成・SHA-256・未検証範囲は [TEST_RESULTS](TEST_RESULTS.md) を参照してください。Forge の GUI 試験は開発ラン構成、Fabric は最終配布 JAR を直接読み込む構成です。
