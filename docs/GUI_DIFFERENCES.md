# GUI デザインとの差分 — 0.1.0-alpha.2

元のサイバーパンク風 GUI リファレンスとの比較記録です。元画像と個人向け依頼文は公開用ソースには含めていません。

画像の配色・半透明パネル・左ナビ・キャラクタープレビューをコードで実装しています。画像を操作画面の背景として貼り付ける方式ではありません。実際の入力・描画試験の範囲と取得画像は `TEST_RESULTS.md` を参照してください。

| 要素 | 添付デザイン | 現在の実装 |
|---|---|---|
| 基本構成 | ゲーム画面上に大型サイバーパネル | 半透明の黒いパネル、シアン / パープルの枠、操作可能な Widget |
| 外枠と発光 | 回路模様、強いブルーム、紫の稲妻 | 直線枠と追加アウトライン。G ボタンで追加発光を独立切替。回路模様・ブルームシェーダーは含まない |
| ヘッダー | 斜体の大型タイトル、顔、固定キー情報 | ゲーム標準フォント、タイトル、状態、閉じる / G / K ボタン。操作ラベルは現在のキー割り当てを表示 |
| 左ナビ | アイコン付きの主カテゴリ | 12 カテゴリを文字ボタンで表示。選択色・説明ツールチップ・独立スクロール |
| キャラクター | 大きいヘロブラインと補助プレビュー | 実プレイヤーの立体プレビューを一つ表示。マウスに合わせて回転 |
| 狭い画面 | 横長の固定構成 | パネル幅 620 未満、または本文高さ 150 以下ではプレビューを省略して操作部を優先 |
| トグルと倍率 | 複数パネルへ並列配置 | 選択カテゴリ内にトグル、説明、アクション、スライダーを配置。移動 / 攻撃速度 10 倍、採掘 100 倍、威力 1000 倍まで |
| 下部ステータス | 顔・ハート・空腹アイコン・経験値バー | HP / 最大 HP、満腹度、レベルを文字表示。装飾アイコン・経験値バーは含まない |
| 下部操作 | 一括切替、地点保存、帰還、詳細設定 | 一括切替、地点保存、帰還を固定配置。右上 K ボタンから標準のキー割り当て画面へ移動 |

| 通知 | 王冠付きの右上通知 | GUI 状態表示と Minecraft のゲーム内メッセージを使用 |
| 表記 | 英語 / 日本語の装飾文字と生成由来の誤字 | 翻訳キーによる日本語 / 英語の可読テキスト |

## 操作対応

- Tab / Shift+Tab で移動すると、画面外のフォーカス項目を表示範囲へスクロールします。
- マウスホイールと PageUp / PageDown、Alt+↑ / ↓、ボタンとスライダーの標準キー操作に対応します。
- スクロール領域は描画とクリック判定を同じ範囲へ制限します。スライダーを範囲外で離した場合や画面を閉じた場合も、操作中の値を送信します。
- G ボタンのパネル発光は端末設定へ自動保存し、Effects と独立しています。
- サーバーの承認済み状態を表示します。標準設定ではチート OFF・OP なしで操作できます。任意の制限モードを有効にしたサーバーでは、その許可状態に従います。
- 実体のある落雷・即死相当攻撃・地形変更には確認画面を挟みます。これは OP 要求ではありません。

画像との残る差は主に装飾と情報の配置です。FPS、各種装備・シェーダー・他 MOD の描画との組合せは、実際の測定条件ごとに `TEST_RESULTS.md` へ記録します。
