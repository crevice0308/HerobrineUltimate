# 実施したセキュリティ確認

対象: 0.1.0-alpha.2 / 2026-10-17。これはソースレビューと限定した依存関係の照合結果です。侵入試験・全推移依存の監査・安全性の認証を意味しません。

## ソース確認

- C2Sはクライアントが指定したUUIDを利用せず、接続のServerPlayerを使用。サーバーのメインスレッドで操作する。
- ローダー受信時にC2Sを8192 bytes以下へ制限。サーバー処理はキー数・文字長・型・既知操作・有限倍率・権限・頻度を検査。
- 標準は `require-permission=false` で、チートOFF・非OP・非所有者の参加者も能力を利用できる。`true` を明示した場合だけOP level2 / 所有者 / UUID許可リストを判定し、権限変更をtickで反映する。
- 視線先、対象、距離、ワールド境界、読み込み済みチャンク、安全な着地候補はサーバーが計算する。
- 実体のある雷はサーバー設定＋確認、地形変更は確認＋最大27ブロック＋通常の採掘処理を使う。PvPの特殊攻撃は既定で無効。
- アカウント名・認証・UUIDや署名付きチャットの本文を変更する処理、外部コマンド実行、能力のための外部HTTP通信はない。
- 各倍率は移動10・採掘100・攻撃速度10・威力1000まで。非有限値を拒否。
- 独自UUIDの属性modifierだけを除去し、飛行と透明化の基準状態を復元。サーバー設定の不正なUnicodeも起動時に捕捉。

## 依存関係データベース照合

OSV APIへ次のMaven座標を照会した生データを 開発時の記録に保存した。生データは公開用ソースには含めていない。

| 座標 | 照会結果 | 範囲 |
|---|---|---|
| net.fabricmc:fabric-loader 0.16.14 | 一致する記録なし | 網羅的な安全性確認ではない |
| net.minecraftforge:forge 1.20.1-47.4.10 | 一致する記録なし | 未登録の座標や推移依存は別途必要 |
| io.netty:netty-buffer 4.1.82.Final | 一致する記録なし | Nettyの他モジュール全体の結果ではない |
| com.google.guava:guava 31.1-jre | 2件の記録あり | Minecraft系実行環境の依存関係 |

Guava31.1-jreにはGHSA-5mg8-w23w-74h3（CVE-2020-8908）とGHSA-7g45-4rm6-3mm3（CVE-2023-2976）が一致した。どちらも一時ディレクトリ関連の既知問題。MOD自身はGuavaの該当一時ディレクトリAPIを呼び出していないが、ゲーム全体の利用箇所や到達可能性は未検証。MODのJARにGuavaを同梱・置換して解消したとは扱わない。

公式の修正状況は以下を参照。

- https://github.com/google/guava/issues/4011
- https://github.com/google/guava/issues/6532
- https://osv.dev/vulnerability/GHSA-5mg8-w23w-74h3
- https://osv.dev/vulnerability/GHSA-7g45-4rm6-3mm3

残作業: 完成JARから解決された全依存をSBOM化し、各ローダーがサポートする形で修正可能な版を評価する。古いMinecraft本体のライブラリを無条件に差し替えることは互換性を含めた検証が必要。

## alpha.2の実行確認

Forge47.4.10とFabricLoader0.16.14の実Minecraft GameTestで、標準の非OP利用、任意の制限モード、不正値、遮蔽物、確認操作と除外ブロックなどを実行した。最終結果はTEST_RESULTSを参照。Fabricネットワークは実NBTとNettyを使い、空・非Compound・余剰バイト・不正な長さ・サイズ境界を検査する追加テストを用意した。

本MODはGuavaをJARに同梱せず、Mojang/ローダーが提供する依存関係を使用する。前回の限定OSV照合結果は既存データベース照合の記録として保持しており、今回すべての推移依存を新たに脆弱性なしと認定したという意味ではない。
