# Asset provenance

`herobrine.png` and `herobrine_eyes.png` are original 64×64 pixel textures authored specifically for this project using geometric UV rectangles. No Mojang skin, game binary, screenshot or external skin was copied. They are included under this project's MIT license. The supplied cyberpunk reference is used as a visual design guide, not packaged as a game background. Minecraft itself and Mojang mappings retain their owners' licenses and are not redistributed. The name Herobrine refers to community folklore; this project is unofficial.
