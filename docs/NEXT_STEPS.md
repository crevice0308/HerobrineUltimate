# 残る確認事項 — 0.1.0-alpha.2

要求の能力カテゴリは実装済みです。要求との対応は `FEATURE_COVERAGE.md`、実行したテストと未検証範囲は `TEST_RESULTS.md` にまとめています。実装の有無と、全環境での検証完了は分けて管理します。

追加で確認する順序：

1. 基準構成でゲーム内テストを通した後、別の実機・クリーンな配布構成で導入、保存、再起動、再接続を確認します。
2. 2 台以上のクライアントで、頭上名・TAB・署名付きチャット、変身の他者表示、各プレイヤーの設定の独立性を確認します。
3. 元スキンの標準幅 / スリム、1 人称の左右の腕、3 人称、装備、しゃがみ・泳ぎ、明所 / 暗所を比較します。
4. Forge / Fabric の追加候補版と、描画・チャット・飛行・地形保護などの他 MOD を、組合せを固定して確認します。
5. GUI スケール・物理解像度ごとの見やすさ、実機の FPS / フレーム時間を測定します。Xvfb やソフトウェア描画の値を実機性能へ一般化しません。
6. 依存先を更新する際は `SECURITY_REVIEW.md` の照合を更新し、両配布 JAR の起動と能力の回帰試験を実行します。

添付画像との残る装飾差や配置差は `GUI_DIFFERENCES.md` に記載しています。未確認のテストを成功としたり、装飾の差を隠したりして完成扱いにはしません。
